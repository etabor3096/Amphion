# Amphion
An AI-powered mobile app that listens to a song, live or from an uploaded file, and generates synced guitar and bass tabs so beginner and intermediate players can learn and play along.

## Documents

- [`docs/SDD.pdf`](docs/SDD.pdf): the Software Design Document (v0.3), the authority on behavior.
- [`docs/SDD.txt`](docs/SDD.txt): plain-text copy of the SDD for search and for agents that can't read PDFs.
