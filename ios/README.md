# ios/

The native iPhone app: Swift, SwiftUI and AVFoundation, iOS 17 or later (SDD 5.1, DD-04, RC-14).

Belongs here: the Xcode project and everything it builds. Planned layout (ARCHITECTURE.md, Repository layout):
`App/`, `Features/` (one folder per screen), `Services/`, `Models/`, `DesignSystem/`.

Does not belong here: the React click-through demo (`../demo/`), the processing code (`../pipeline/`), or secrets.
`GoogleService-Info.plist` stays out of git (RC-06, OD-03).

Empty until P0-02 creates the Xcode project.
